# Algorithm Challenge #44 – Remove Punctuations from a String (Level 3)

🧠 Problem Description  
-
This program removes all punctuation characters from a string  
while keeping letters, spaces, and other valid characters intact.

---

💡 What You’ll Learn
-
- Character-by-character string processing
- Using `ispunct()` for character classification
- Filtering unwanted data from text
- Writing clean and focused string utilities
- Understanding low-level text manipulation

---

🧩 Example
-
**Input:**  
Welcom; To KSA , KSA: is a: 'nice' Country:

**Output:**  
Welcom To KSA  KSA is a nice Country

- **Language:** C++  
- **File Name:** remove_punctuation.cpp

💬 Programming Concept
-

Scanning raw input and selectively keeping only

This concept is fundamental in text processing,
data cleaning, and input validation.
